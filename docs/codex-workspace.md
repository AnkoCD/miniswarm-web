# Codex 风格工作台

## 页面结构

- 左栏：新建任务、运行队列、全局搜索、Skills、归档、记忆和项目树。
- 中栏：项目会话、聊天流、Agent 执行记录、产物预览和统一输入框。
- 右栏：计划、Agents、文件、来源、审批、工具记录和用量。
- 平板端将右栏变为抽屉；手机端隐藏左栏并提供底部导航。
- 主题按钮在左栏底部，选择会保存在当前浏览器；黑色主题使用纯黑背景和纯白正文。
- 代码、工具记录和重点信息使用中性灰色背景；网页与 UI 设计类任务的标题提示使用蓝色。

## 项目与权限

每个用户首次进入时自动创建一个“未归类”项目。项目成员角色为：

- `OWNER`：项目设置、成员、文件、记忆和任务的完整权限。
- `EDITOR`：可编辑项目内容、上传文件和创建任务。
- `VIEWER`：只读浏览项目、任务、文件和来源。

管理员没有全局穿透权限，必须被项目 Owner 显式邀请。
如果浏览器保存的项目 ID 已归档、被移除或不可编辑，新建任务页会自动回退到
第一个可编辑项目；发送前还会再刷新一次项目列表。

## 会话和执行

同一输入框支持 `chat`、`task` 和 `revise` 三种模式。用户消息使用
`client_message_id` 幂等写入，任务创建使用 `client_request_id` 幂等写入。
助手回复通过 SSE 发送 `message.started`、`message.delta`、
`message.completed` 和 `message.failed`；流式内容定期保存到 PostgreSQL，
刷新或断线后可从持久化消息与事件恢复。

输入草稿、模型/思考/自主模式和 Skill 选择按项目保存在当前浏览器。附件可分批追加、单独移除，上传时最多并行 3 个文件。事件刷新会自动合并；用户向上阅读时停止自动滚动，并提供“回到最新消息”。失败或取消的任务可以直接在工作台重试。

## 文件和来源

项目文件按文件名创建递增版本。任务仅获得所选版本的只读快照，不直接修改
项目原件。上传的 PDF、图片和 Office 文件会检查文件签名，明显的 MIME 伪造
会被拒绝。联网来源和用户 URL 保存到 `task_sources`，密钥类查询参数会在入库
前清除。

产物的“预览就绪”只代表结构可读取；只有程序化交付门禁确认 Reviewer 已逐一检查后才标记为“已验证”。

## 数据迁移

迁移 `0013_codex_workspace` 为每个现有用户创建“未归类”项目，并把既有任务
关联到对应项目；同时新增项目、成员、版本文件、项目记忆、来源及流式消息字段。
生产升级前必须先备份 PostgreSQL 与任务文件目录，再执行 Alembic 升级。
